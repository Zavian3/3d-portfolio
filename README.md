# Muhammad A. Rafay — 3D Portfolio

Interactive neural-field portfolio for [Muhammad A. Rafay](https://github.com/Zavian3), Senior AI/ML Engineer in Lahore.

Live content is drawn from his public GitHub profile, LinkedIn, and [NetronFlow](https://netronflow.com).

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

The Vite `base` is relative (`./`), so the site can be hosted on GitHub Pages, Vercel, Netlify, or any static host.

To publish on GitHub Pages: **Settings → Pages → Source: GitHub Actions**. The workflow on `main` builds and deploys automatically. After the first successful run the site will be at `https://zavian3.github.io/3d-portfolio/`.

## Stack

- React + Vite
- Three.js / React Three Fiber
- Drei + Bloom
- Framer Motion
